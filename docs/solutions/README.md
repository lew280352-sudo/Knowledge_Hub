รวมโจทย์หลัก 70 ข้อ: คลื่น 20 ข้อ, แสงเชิงคลื่น 10 ข้อ, แสงเชิงรังสี 20 ข้อ, เสียง 20 ข้อ และตัวอย่าง Ex หน้า 2 มีกราฟผลรวมคลื่นและการสะท้อนปลายตรึงประกอบ

อ้างเลขหน้าจาก PDF ต้นฉบับ 58 หน้า ดู [หลักฐานแก้ปัญหาการอ่านจำนวนหน้า](../pdf-page-count-correction.md) คำตอบนี้อิงโจทย์ใน PDF จริง ไม่ใช่คำตอบของโจทย์ดัดแปลงบนเว็บ

จุดที่ยังต้องระบุเงื่อนไข:

- คลื่นข้อ 6: เฟสเริ่มต้นขึ้นกับว่าเขียนสมการด้วยไซน์หรือโคไซน์ จึงระบุธรรมเนียมก่อนเลือกคำตอบ
- แสงเชิงคลื่นข้อ 7: ไม่ระบุลำดับแถบมืด ผลทั่วไปคือ a = 2nλ; ข้อ 4 ใช้เมื่อ n = 1
- เสียงข้อ 18: ข้อความช่อง ค ในตัวเลือก 5 ไม่สมบูรณ์ จึงแสดงว่าเป็นตัวเลือกตามเจตนาที่คาดได้และขอให้ยืนยันข้อความก่อนใช้เป็นเฉลยเด็ดขาด

ทุกข้อมีหน้าอ้างอิง คำตอบ วิธีทำ สมการ และหมายเหตุเมื่อจำเป็น ต้นฉบับ PDF ไม่ได้ถูกแก้ไข

## ตรวจสอบและสร้างใหม่

ใช้ Node 24 และ Python 3.12+ จากราก repository:

```sh
python -m pip install -r scripts/validation/requirements.txt
npm run validate:pdf-solutions
# เมื่อต้องการสร้างกราฟใหม่ด้วย
python -m pip install matplotlib
python scripts/solutions/plot-engineering-examples.py
# ใช้ Chromium ของ Playwright สำหรับพิมพ์ PDF
npx playwright install chromium
node --experimental-strip-types scripts/solutions/build-engineering-solutions.mjs
```

ตัวตรวจแยกตรวจเลขและสูตรจากค่าที่ให้ใน PDF 61 รายการ พร้อมเงื่อนไขคำตอบที่ยังไม่แน่นอน และยืนยัน SHA-256 ว่าอ่านจากต้นฉบับที่ระบุ การเรนเดอร์ใช้ KaTeX แบบ strict และแบบอักษรไทยที่ฝังในไฟล์ HTML เพื่อเปิดอ่านออฟไลน์ได้
