# บันทึกการตรวจสอบ

วันที่ 2 พฤศจิกายน 2026 (Asia/Bangkok)

## ผลตรวจในเครื่อง

- `npm test`: ผ่าน 17 tests รวม 70 baseline fixtures ที่คำนวณแยก, 5,600 seeded variants, SQLite persistence จริง, owner isolation, revision conflict, retry, deadline, คะแนน 80%, คะแนนสูงสุด และประวัติเกิน 100 ชุด
- `npx tsc --noEmit`: ผ่าน
- `npx playwright test`: ผ่าน 7 flows ใน Chromium: เรียนต่อ/เกม/สอบ/เฉลย/ประวัติ; สอง contexts ใช้ D1 เดียวกัน; stale revision และ failed-save recovery; ปฏิเสธตัวตนปลอมและ origin ภายนอก; ไม่เผยค่าคำตอบผ่านภาพ; game save race; รูปเลนส์/กระจกกับ f ลบ; ลิงก์ตรงหลังเข้าสู่ระบบ
- Production build ผ่านระหว่างพัฒนา และจะสร้างใหม่จาก source สุดท้ายด้วย Sites source helper ก่อน publish
- ตรวจภาพ desktop 1440px, tablet 820px และ mobile 390px และเช็ก horizontal overflow / page errors
- Impeccable mechanical detector: ไม่มีรายการที่ตรวจพบ (`[]`)

การทดสอบเบราว์เซอร์ใช้ local Sites auth emulator กับ local D1 ไม่ได้คัดลอก localStorage เพื่อจำลองการซิงก์ ผลทดสอบสอง contexts จึงมาจาก API/ฐานข้อมูลร่วมจริง การบังคับสิทธิ์บัญชี ChatGPT บนโฮสต์จริงเป็นหน้าที่ของ Sites owner-private boundary และการยืนยัน publication จากแพลตฟอร์ม

## ผู้ตรวจอีกคนและการแก้ไข

ผู้ตรวจอิสระตรวจโค้ดทั้ง branch และทดสอบตัวอย่างด้วยการ render ภาพ, SQLite และ browser พบประเด็นสำคัญ 5 ข้อ ซึ่งแก้พร้อม regression tests แล้ว:

1. ภาพระหว่างสอบเคยแสดงค่าที่คำนวณได้: เพิ่ม question presentation แสดงเฉพาะข้อมูลโจทย์ ซ่อน readout/ผลรวม/รังสีสะท้อนที่เป็นคำตอบ และส่งระยะ u/v แทน f ที่เป็นคำตอบ
2. คลื่นนิ่งเคยใช้ความเร็วเสียงเริ่มต้น 340 m/s: ใช้ความถี่ที่โจทย์กำหนดและ λ จากความยาว/จำนวนพู ให้ภาพและเฉลยตรงกัน
3. กดเล่นเกมใหม่ระหว่างบันทึกรอบก่อนทำให้สถานะ saved ข้ามรอบ: รอผลรอบเดิมบันทึกสำเร็จก่อนเริ่มใหม่หรือไปข้อสอบ หากบันทึกล้มเหลวมี retry
4. ประวัติที่เก่ากว่า 100 ชุดเข้าถึงไม่ได้: โหลด summary ของทุกรอบ และดึง question snapshots เมื่อเปิดรอบนั้น โดยไม่บรรทุกเฉลยทั้งหมดในหน้าแรก
5. รูปเลนส์/กระจกไม่เปลี่ยนตามเครื่องหมาย f: เปลี่ยนรูปตามชนิดจริงและตรวจเส้นขอบเลนส์เว้า พร้อมแสดงชื่อชนิดให้ชัด

แก้ข้อเสนอเรื่อง resume ให้ใช้ด่านที่ยังไม่ผ่านและมี `updatedAt` ล่าสุด เพิ่ม regression test; ไม่เหลือข้อย่อยที่เลื่อนแก้ และแก้เพิ่มเติมให้ลิงก์ด่าน/ข้อสอบอยู่ครบหลังเข้าสู่ระบบจากเครื่องใหม่

## ขอบเขตการยืนยัน

ทุกแม่แบบมี baseline oracle คงที่และตรวจหลาย seed แต่ไม่อ้างว่าเอกสารต้นฉบับมีเฉลยทางการ ข้อที่ดัดแปลง/เงื่อนไขที่ทำให้ชัดขึ้นอยู่ใน `content-inventory.md` การทดสอบตรวจสมการและพฤติกรรมที่สร้างไว้ ไม่รับรองการทำข้อสอบจริงทุกสำนักหรือการตีความรูปที่กำกวมโดยไม่ระบุเงื่อนไข

ฐานข้อมูล local สำหรับ QA แยกจาก production จึงไม่ส่งคะแนนหรือประวัติทดสอบขึ้นเว็บจริง เว็บไซต์เผยแพร่เป็นส่วนตัวและต้องใช้บัญชี ChatGPT เจ้าของเดียวกันในแต่ละอุปกรณ์
